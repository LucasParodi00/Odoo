# FullCalendar Integration

Para integrar FullCalendar, descargue los siguientes archivos:

1. Descargar FullCalendar v6 desde: https://fullcalendar.io/
2. Copiar los archivos a este directorio:
   - `index.global.min.js`
   - `locales/es.global.min.js`

Los archivos deben estar en:
- `gestion_turnos/static/lib/fullcalendar/index.global.min.js`
- `gestion_turnos/static/lib/fullcalendar/locales/es.global.min.js`

Una vez descargados, descomente las líneas correspondientes en el archivo `__manifest__.py`.

Por ahora, el módulo utiliza el calendario estándar de Odoo que es completamente funcional.
